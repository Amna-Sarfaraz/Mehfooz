# Mahfooz Setup

## Stack

- Next.js 14
- React 18
- Tailwind CSS 3
- Lucide React

## Runtime

- Node.js 18.17+ or 20+
- npm 9+

## Install

```bash
npm install
```

## Run locally

```bash
npm run dev
```

## Package dependencies

Core:
- `next@^14.2.30`
- `react@^18.3.1`
- `react-dom@^18.3.1`
- `lucide-react@^0.511.0`

Development:
- `tailwindcss@^3.4.17`
- `postcss@^8.5.6`
- `autoprefixer@^10.4.21`
- `eslint@^8.57.1`
- `eslint-config-next@^14.2.30`
